Historique

    Outil d’analyse technique à titre informatif, basé sur des données de marché réelles. Aucune garantie de résultat : le trading et les options binaires comportent un risque élevé de perte en capital. Application indépendante, non affiliée à Pocket Option.

    Sources de données

    Crypto spot : Binance. Marchés classiques : Twelve Data (Forex, matières premières, actions, indices et cryptos). OTC : OTCharts via le serveur.

    La clé Twelve Data reste dans ce navigateur. La clé OTCharts doit être configurée comme variable secrète OTCHARTS_API_KEY sur le serveur : ne la collez jamais dans cette page. Les symboles visibles ne garantissent pas leur accès : celui-ci dépend du fournisseur et de votre forfait.
